## Risks / notes
- The deck page can't show interval labels for cards that are already learned, because `CardResponse` has no SM-2 state, so it hides them. New cards show "1 ngày" on all four buttons, which is correct for SM-2 with n=0.
- The daily limit applies per session (reloading starts a new session of up to N cards). There is no storage key for a per-day count.
- Rating keys rely on `useHotkeys` `preventDefault` so a focused button is not activated twice by Space/Enter.
- No E2E run against T05; this branch was coded against the contract and the T05 branch.
