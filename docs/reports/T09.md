## Cross-task requests / notes

- **T02 (gateway):** `PUT /practice/shadowing/recordings/{id}` sends a raw `audio/wav` body of up to about 1 MB (30 s × 32 KB/s). The gateway proxy must stream or forward raw bodies without a JSON body parser and allow at least 2 MB, otherwise local-mode upload breaks.
- **T08 (result screen):** shadowing writes `submits` and `ms` to the `parroto:session:{lessonId}:shadowing` session store (no `replays` from Recorder; model-audio replays are counted by `useSentenceAudio`).
- **T11:** `PhonemeScoreView` props stay backward compatible (`words` only); it is now a client component with an internal selection state.
- **T01/README:** recording needs HTTPS or `localhost`. A LAN IP over plain HTTP shows the "insecure" panel.

## Risks

- Real-browser behaviour (AudioWorklet from a Blob URL under Safari, permission flows) was not tested here. The ScriptProcessor fallback covers worklet load failures.
- `downsample` uses a simple box filter rather than a proper FIR low-pass. That is enough for speech scoring, but slight aliasing is possible at 44.1 kHz.
- If a page CSP is ever added, it must allow `blob:` for `worklet-src`/`script-src`, or capture falls back to ScriptProcessor.
